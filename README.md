# Scripture Publications

Kolekcja publikacji w formacie PDF związanych ze studiowaniem Pisma Świętego, języków biblijnych i tekstów judaistycznych.
Wszystkie zasoby w tym repozytorium są dostępne do **otwartego użytku** (open use), zgodnie z licencjami zawartymi w poszczególnych publikacjach. Tłumaczenia i opracowania znajdują się w **stanie draft** (wersja robocza) i mogą ulec zmianie. Zasoby są przeznaczone również dla projektu **scripture.pl**.
